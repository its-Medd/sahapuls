## Missing features and architecture

Soil moisture, water level, alert acknowledgment/recovery/history, deterministic scenarios, simulator controls, settings and device naming are absent. Existing functional modules include threshold comparison, parameterized SQLite queries, basic history aggregation, MQTT pub/sub, React charts/map and Socket.IO broadcasts. Preserve and extend these modules rather than replacing the project.

No migration version tracking, persistent deduplication, explicit database domain constraints or rollback tests exist. History aggregation currently applies a row limit before aggregation: broad ranges can be incomplete. No production authentication, authorization, TLS, retention or backup policy exists. Compose publishes anonymous MQTT and HTTP to all interfaces; constrain the local demo bindings. CORS is not authentication.

## Dependencies and testing baseline

The initial lock contains entries for correctly named directories that are absent on disk; package manifests use @iot-lora-dashboard names. Missing dependency reports cannot be attributed to application code until installation. Original tests cover thresholds, aggregation, ingestion, parser, routes, sockets, simulator helpers/node episodes and three frontend units. No real-broker automated lifecycle or browser E2E suite exists initially. Dependency advisories and test outcomes will be recorded after actual execution in docs/security-review.md and docs/testing.md.

## Low-severity candidates

Confirmed candidates for documented exercises: timeAgo rounds 59.6 seconds to 1 minute early (front/src/lib/format.ts); MetricChart uses only clock labels across multiple dates; MapView always recenters on fleet-average changes and ignores reduced-motion preference. Final retained tasks and exact reproductions belong in docs/open-bug-tasks.md. No defect will be introduced to satisfy a count.

## Final disposition

A01–A06 and A08–A15 were fixed and regression-tested. A07 was corrected after runtime evidence showed the driver already enables foreign keys; explicit configuration and migration tests were added. Initial locations above refer to the original checkout; front and simulatoor are now web and simulator. The map now respects reduced motion; its original motion issue was not retained. The three documented exercises are early relative-time rounding, invalid timestamp formatting and clock-only multi-day chart ticks.

New features and current changes are summarized in submission-report.md. Exact command outcomes are in testing.md. Database migration preserves existing rows and unknown new sensor values. Production deployment risks remain documented. The previous moderate tooling advisory has since been remediated; see the current security review.
