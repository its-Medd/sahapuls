## Confirmed repairs and retained defenses

- Topic/payload identity equality, finite/ranged validation, byte limits, safe sequences and normalized dates before MQTT writes.
- Parameterized queries and atomic device/reading/alert/history writes; only committed values reach Socket.IO.
- Loopback host bindings for local HTTP, MQTT and Compose ports.
- Fixed real localhost/127.0.0.1 mismatch. HTTP CORS, mutation Origin checks and Socket.IO allow the exact configured origin and same-port/same-scheme loopback aliases. Unrelated hosts, ports, suffix tricks and opaque origins are rejected. No-origin local programs remain allowed; Origin checks are not authentication.
- Request size/limit/date validation and explicit analytics source bounds.
- Separate liveness/readiness components without exposing credentials or full database paths. Public health details are acceptable only within the documented local boundary.
- Environment-based credentials; no personal accounts, customer profiles or contact-data collection added.
- Database/user files are ignored by Git; original MIT attribution is unchanged.

## Deployment boundaries

No user authentication, per-device MQTT ACLs, authorization, TLS, rate/connection quotas, multitenancy, retention scheduler or audited backup/restore tooling is implemented. Local processes can submit telemetry, rename devices, acknowledge alerts and control simulation. Application byte limits apply after MQTT receipt; broker-level limits are still needed. Identity/replay checks are not cryptographic device ownership or malicious-replay protection.

Do not publish this demo by simply changing HOST or port bindings. Design identity, transport security and authorization together first. The development runner only manages child processes it starts; reused services are left running. Its marker checks avoid accidental port collisions, not hostile local impersonation.

Map tiles use OpenStreetMap. A failed basemap is labeled and the station list remains usable. Select an appropriate provider/offline basemap before deployment involving location privacy or sustained map traffic.
